Streamlining IT Procurement: Automating Standard Laptop Requests
 Project Overview
This ServiceNow project automates the creation of a Catalog Task for Standard Laptop requests.
 Objective
To reduce manual task creation and automatically route approved laptop requests to the Hardware assignment group.
 Flow
1. Standard Laptop request is submitted.
2. The request goes through the configured approval process.
3. After approval, the Flow creates a Catalog Task.
4. The Catalog Task is assigned to the Hardware assignment group.
 Technology
- ServiceNow
- Flow Designer
- Service Catalog
- Catalog Task
 Project Status
Milestone 1: Flow
